# PythonAnywhere Deployment Guide

Follow these steps to deploy your Trailcam Photo Processor to PythonAnywhere.

## 1. Prepare your files
Because we used `.gitignore`, your secrets are **NOT** on GitHub. You must have these files ready on your local computer to upload manually:
1.  `credentials.json`
2.  `token.json` (Generated by running `auth_drive.py` locally)
3.  `.env` (Your configuration file)

## 2. Set up the Project on PythonAnywhere

1.  **Log in** to your [PythonAnywhere dashboard](https://www.pythonanywhere.com/).
2.  Open a **Bash** console.
3.  **Clone your repository**:
    ```bash
    git clone https://github.com/dinkotom/trailcam.git
    cd trailcam
    ```
4.  **Create a Virtual Environment**:
    ```bash
    mkvirtualenv --python=/usr/bin/python3.12 trailcam-env
    ```
    *(Note: The prompt should change to `(trailcam-env) $`)*

5.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

## 3. Upload Secret Files
You need to transfer your local secrets to the server.

1.  Go to the **Files** tab in your PythonAnywhere dashboard.
2.  Navigate to the `trailcam` directory (e.g., `/home/dinkotom/trailcam`).
3.  Use the **"Upload a file"** button to upload these 3 files from your computer:
    -   `credentials.json`
    -   `token.json`
    -   `.env`

## 4. Test the Setup
Back in your **Bash** console (make sure `trailcam-env` is active), run a test:

```bash
# If your virtualenv isn't active, activate it first:
# workon trailcam-env

python src/main.py
```

-   If it works, you should see "Fetching recent emails..." and "Processing complete."
-   If it fails (e.g., *ModuleNotFoundError*), ensure you are in the `trailcam` folder and the virtualenv is active.

## 5. Automate with Scheduled Tasks
1.  Go to the **Tasks** tab in PythonAnywhere.
2.  Create a **Scheduled Task** to run **Hourly** (e.g., at 0 minutes past the hour).
3.  **Command to run**:
    Use the main script directly.

    ```bash
    /home/dinkotom/.virtualenvs/trailcam-env/bin/python /home/dinkotom/trailcam/src/main.py
    ```

    *(Replace `dinkotom` with your username if widely different)*

4.  Click **Create**.


## Troubleshooting
-   **Token Expiry**: If your Google Cloud project is in "Testing" status, the `token.json` will expire in 7 days. You will need to re-run `auth_drive.py` **locally** on your computer to generate a new `token.json`, and then upload it to PythonAnywhere again. To avoid this, push your Google Cloud OAuth app to "Production" (verification not required for personal use).
